Reward-hacking auditor

Measures whether a test suite can be passed without solving the task. A local 7B model, given only the problem and its three published tests, writes code that passes without solving on 36% of 890 MBPP problems. The standard fix is to add more held-out tests drawn the same way. I replayed all 857 model-written false positives and sorted them by which region of the input space they are actually wrong on. Held-out tests remove 67.0% of the failures that live on ordinary inputs and 3.9% of the ones that live only on empty input or zero, so the defence works on the failures the suite could already catch and concentrates the ones it never looks at. Four models, roughly 8,900 generation attempts each, scored against an independent oracle built from EvalPlus rather than my own fuzzer. Pre-registered, with both bugs found since and one wrong prediction left standing in the record.

Learned-guide search for Rush Hour

Asks whether a learned action-value function orders search better than a hand-designed heuristic. A two-tower Q(s,a) network is regressed on exact breadth-first-search distances, then fine-tuned with Double DQN under three potential-based reward forms including Ng-Harada-Russell shaping. Five-fold cross-validation over 150 instances, every instance held out exactly once, three seeds. The supervised guide solves 132 ± 2 of 150 held-out instances at 115,000 ± 7,000 nodes against the hand-tuned potential's 104 at 190,192, so 28 more instances with 40% fewer nodes. Reinforcement learning fine-tuning gives no measurable further gain over 15 fold-runs, which overturned my own earlier result from a single unseeded run. I also ablated all ten terms of the heuristic and found one that never fires on the corpus, so its weight had never been tested.

Buoy siting evaluator

A function that scores any location in US waters for how much a new NOAA weather buoy there would tell you that the existing network does not. Decorrelation lengths measured from hourly records across 163 scored stations. Wave height decorrelates over 780 to 838 km in every basin while wind runs 343 km in the Pacific against 542 in the Atlantic, so how far apart stations should sit depends on which variable you want to know. A 34,709-point quarter-degree candidate grid over five regional boxes, filtered to 21,006 feasible sites using depth and distance bounds taken from the 1st and 99th percentiles of the existing moored fleet.

Congestion potential search

A potential-guided local search for Rush Hour. A ten-term congestion potential over board configurations, proven zero exactly when the puzzle is solved and verified over 192,824 reachable states with no violations.
